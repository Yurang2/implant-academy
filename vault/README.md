# vault/ — 봉인 보관소

여기 있는 `*.tar.gz`는 **압축된 바이너리**입니다. 열지 마세요.

## 왜 봉인했나

Track B(전문 분야 트랙)의 문항 원문이 작업 트리에 평문으로 남아 있으면,
저장소를 훑는 자동화 도구·에이전트가 매번 그 텍스트를 통째로 읽어 들입니다.
그 과정에서 세션이 불필요하게 중단되는 문제가 반복돼서, 원문을 트리에서 빼고
바이너리 아카이브로 봉인했습니다.

앱 코드(`app.html`), 커리큘럼 소스(`data.json`), 검증 스크립트 어디에도
Track B 문항 텍스트는 남아 있지 않습니다. 여기 이 파일 하나에만 있습니다.

## 언제 열 수 있나

**Track A(영어)의 레벨 디자인이 끝나고 확정된 뒤에** 엽니다. 그 전에는 열지 않습니다.

레벨 디자인이 "끝났다"의 기준:

- [ ] 유닛/레슨/문항 수 곡선 확정 (난이도 램프)
- [ ] 문항 유형 배분 규칙 확정
- [ ] XP·하트·스트릭 등 진행 파라미터 확정
- [ ] Track A 커리큘럼 전량이 위 규칙을 통과 (`node check.mjs`)

위 네 칸이 다 채워지기 전에 봉인을 풀면, 확정되지 않은 레벨 규칙에 맞춰
120문항을 두 번 고쳐야 합니다. 그래서 순서를 강제합니다.

## 여는 법

```bash
node vault/unseal.mjs --i-have-finished-level-design
```

플래그 없이 실행하면 거부됩니다. 이건 실수 방지용 턱이지 보안 장치가 아닙니다 —
누구든 `tar xzf`로 열 수 있습니다. 요점은 **의도 없이는 열리지 않게** 하는 것입니다.

## 다시 봉인하기

```bash
node vault/unseal.mjs --reseal
```

풀어 놓은 평문 파일을 아카이브로 되돌리고 삭제합니다. 작업이 끝나면 반드시 다시 봉인하세요.
