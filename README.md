# 링고 아카데미 🌐

듀오링고·스픽을 레퍼런스로 만든 단계별 영어 학습 웹앱. 모바일 우선 디자인, 설치·서버 없이 HTML 파일 하나로 동작합니다.

**바로 학습하기 → https://yurang2.github.io/implant-academy/**

## 사용 방법

- 위 주소를 열면 바로 시작됩니다. 내려받은 경우 `index.html`을 브라우저로 열어도 동일하게 동작합니다.
- 처음 접속 시 **성명(한글 2~4글자)** 을 입력하면 프로필이 만들어지고, 같은 기기에서 같은 이름을 입력하면 학습 기록이 다시 로드됩니다.
- 학습 데이터는 브라우저 `localStorage`에 자동 저장됩니다. 기본은 기기별 저장이고,
  [클라우드 동기화](DEPLOY.md)를 켜면 같은 이름·코드로 여러 기기에서 이어집니다.

## 구성

| 파일 | 역할 |
|---|---|
| `DESIGN.md` | **레벨 디자인의 단일 출처** — 레슨 템플릿·난이도 램프·보상 파라미터·건너뛰기 정책 |
| `app.html` | 앱 본체 (스타일 + 마크업 + 로직 + 주입된 커리큘럼). 로직·스타일 수정은 이 파일에서. |
| `index.html` | `app.html`을 감싼 단독 실행 파일 (빌드 산출물) |
| `data.json` | 커리큘럼 원본 데이터 (트랙 → 유닛 → 레슨 → 문항). **문항 수정은 여기서.** |
| `build.mjs` | 검증 후 `data.json` → `app.html` 주입 + `index.html` 생성 |
| `check.mjs` | DESIGN.md 규칙의 기계 강제 버전. `build.mjs`도 이걸 불러 씁니다. |
| `dupcheck.mjs` | 같은 지식을 반복해 묻는 문항 찾기 |
| `vault/` | 봉인 보관소 — [vault/README.md](vault/README.md) 참고 |

```bash
node check.mjs      # 데이터 검증 (오류 있으면 종료 코드 1)
node dupcheck.mjs   # 중복 문항 점검
node build.mjs      # 주입 + index.html 생성
```

## 투트랙 구조

`data.json`은 **트랙 배열**입니다. 엔진(문항 유형·XP·하트·스트릭·경로 UI)은 전부 공용이고, 트랙은 콘텐츠만 갈아 끼웁니다.

```json
{ "schema": 2, "tracks": [
  { "id": "english", "title": "생활 영어", "lang": "en-US", "status": "live",   "units": [...] },
  { "id": "track-b", "title": "전문 트랙",  "lang": "ko-KR", "status": "sealed", "units": []    }
]}
```

- `status: "live"` 이고 `units`가 있는 트랙만 앱에 나타납니다.
- live 트랙이 2개 이상이면 상단에 **트랙 전환 칩**이 자동으로 켜지고, 진도는 트랙별로 따로 저장됩니다(레슨 id가 `트랙id:u1l1` 형태).
- live가 아닌 트랙은 홈 맨 아래에 잠금 카드로만 표시됩니다.

두 번째 트랙을 붙이는 순서는 [vault/README.md](vault/README.md)에 적어 두었습니다. 요약하면 **영어 트랙 레벨 디자인 확정 → 그 규칙으로 2번 트랙 문항 재단 → `status`를 `live`로**. 반대로 하면 문항을 두 번 고치게 됩니다.

## 커리큘럼 (생활 영어)

**7개 레벨 밴드 · 22개 유닛 · 88개 레슨 · 528문항** (A1.1 → B1.1)

밴드마다 담당 문법이 있고, 각 밴드는 *문법 유닛 → 그 문법을 쓰는 상황 유닛* 순서입니다.
아직 배우지 않은 문법이 문항에 등장하면 `check.mjs`가 오류로 막습니다 — 이것이 커리큘럼이
체계를 유지하는 장치입니다 ([DESIGN.md §3.5](DESIGN.md)).

| 밴드 | 담당 문법 | 유닛 |
|---|---|---|
| **A1.1** 영어의 뼈대 | be동사·인칭대명사·관사·복수형 | 나와 너 · 이것과 저것 · 첫 인사와 소개 |
| **A1.2** 매일의 동작 | 일반동사 현재·3인칭 -s·do/does | 매일 하는 일 · 묻고 답하기 · 하루 일과 |
| **A1.3** 지금, 여기 | 현재진행형·전치사 | 지금 하는 중 · 카페와 식당 · 길 위에서 · 쇼핑 |
| **A2.1** 지난 일 말하기 | 과거시제(be·규칙·불규칙)·did | 어제는 어땠어요 · 지난 일 말하기 · 날씨와 스몰토크 |
| **A2.2** 앞일과 의무 | will·be going to·should·have to·must | 앞으로의 일 · 해야 하는 일 · 일과 약속 · 공항과 비행기 |
| **A2.3** 견주어 말하기 | 비교급·최상급·수량 표현 | 견주어 말하기 · 호텔에서 |
| **B1.1** 문장을 잇다 | 현재완료·관계대명사 | 해 본 적 있어요 · 설명을 덧붙이기 · 감정과 의견 |

## 문항 유형

듣기·말하기 3종이 이 앱의 중심입니다. 레슨은 6문항 고정이고
**듣기 → 인식 → 조립 → 말하기** 순서를 따릅니다 — 자세한 규칙은 [DESIGN.md](DESIGN.md).

| 유형 | 하는 일 | 필수 필드 |
|---|---|---|
| `listen` | TTS로 문장을 들려주고 보기에서 고르기 (천천히 듣기 지원) | `audio`, `options`(4), `answerIndex` |
| `speak` | 문장을 따라 말하면 음성 인식으로 단어별 채점 — **선택 유형** (신규 유닛은 저작하지 않음) | `text`, `meaning` |
| `wordbank` | 단어 타일을 눌러 영어 문장 조립 | `prompt`, `answer`, `extra`(오답 타일), `accept`(대체 정답, 선택) |
| `choice` | 4지선다 | `prompt`, `options`(4), `answerIndex` |
| `blank` | 빈칸 채우기 (`___` 자리에 타일) | `prompt`, `hint`, `options`(4), `answerIndex` |
| `ox` | O/X 판단 | `prompt`, `answerBool` |
| `match` | 영어↔뜻 짝 맞추기 | `pairs`(4쌍) |
| `order` | 대화 순서 배열 (유닛 마지막 레슨의 캡스톤) | `sequence`(3~5) |

모든 문항에 `explanation`이 필요합니다. 저작 규약: 정답은 `answerIndex: 0`에 두면
화면 순서는 엔진이 렌더마다 섞습니다. 규칙의 정확한 정의는 `check.mjs`에 있습니다.

### 음성 기능이 없는 브라우저에서는

- **TTS 미지원**: `listen` 문항이 세션에서 제외됩니다 (답을 글로 보여 주는 것보다 정직합니다).
- **음성 인식 미지원 / 마이크 끔**: `speak` 문항이 세션에서 제외됩니다. 레슨이 막히지 않습니다.
- 말하기 문항의 "지금은 말하기 어려워요"는 그 문항을 채점에서 제외합니다 — 정답 처리가 아닙니다.
- 마이크와 자동 듣기는 프로필에서 각각 끌 수 있습니다.

### 발음 채점 방식

목표 문장을 정규화(소문자화·문장부호 제거·축약형 전개)한 뒤, 인식 결과에 몇 개 단어가 들어 있는지 봅니다. **70% 이상이면 통과**, 놓친 단어는 피드백에 물결 밑줄로 표시됩니다. 순서는 보지 않습니다 — 인식기가 어순을 자주 흔들기 때문입니다.

## 게임 요소

- **오답 노트** — 틀린 문항이 자동으로 모이고, 홈에서 약한 문제만 다시 풉니다. 첫 시도에 맞히면 노트에서 지워집니다
- **클라우드 동기화(선택)** — 서버 주소·코드를 넣으면 기록이 자동 저장되고 기기 간 이어집니다 ([DEPLOY.md](DEPLOY.md) 참고)
- 레슨 시작 시 **'오늘의 표현'** 카드 — 조립·말하기할 문장을 먼저 보여 주고 들려줍니다
- 레슨당 하트 5개 (오답 시 차감, 소진 시 재도전)
- 오답 문항은 레슨 끝에 재출제 (맞힐 때까지)
- XP: 첫 시도 정답 +10 / 재시도 +5 / 퍼펙트 +20 · **복습은 절반**(+5/+2/+10, 문항 순서 셔플)
- 별점(정답률 기준 1~3개), 연속 학습일(스트릭)
- 정답을 맞히면 목표 문장을 한 번 더 들려줍니다 (끄기 가능)
- 효과음(프로필에서 끄기 가능), 다크 모드 자동 지원
