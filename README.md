# 임플란트 아카데미 🦷

임플란트를 이해하고 그 내용을 영어로 말하게 만드는 학습 웹앱. **임플란트 × 영어(기본 트랙)**, **임플란트 임상**, **생활 영어** 세 트랙을 같은 엔진으로 돌립니다. 모바일 우선, 설치·서버 없이 HTML 파일 하나로 동작합니다.

듀오링고처럼 "매일 했는데 느는 걸 모르겠다"가 되지 않도록, XP·하트 대신 **간격 반복으로 쌓인 장기 기억**을 보여 주고, 효과를 판단할 기록(기억률·써먹은 기록·서술 답안)을 남겨 **파일로 내보냅니다**. 설계 근거는 [DESIGN.md §0](DESIGN.md).

**바로 학습하기 → https://yurang2.github.io/implant-academy/**

## 사용 방법

- 위 주소를 열면 바로 시작됩니다. 내려받은 경우 `index.html`을 브라우저로 열어도 동일하게 동작합니다.
- 처음 접속 시 **성명(한글 2~4글자)** 을 입력하면 프로필이 만들어지고, 같은 기기에서 같은 이름을 입력하면 학습 기록이 다시 로드됩니다.
- 학습 데이터는 브라우저 `localStorage`에 자동 저장됩니다. 기본은 기기별 저장이고,
  [클라우드 동기화](DEPLOY.md)를 켜면 같은 이름·코드로 여러 기기에서 이어집니다.

## 구성

| 파일 | 역할 |
|---|---|
| `DESIGN.md` | **레벨 디자인의 단일 출처** — 레슨 템플릿·난이도 램프·보상 파라미터·건너뛰기 정책 |
| `app.html` | 앱 본체 (스타일 + 마크업 + 로직 + 주입된 커리큘럼). 로직·스타일 수정은 이 파일에서. |
| `index.html` | `app.html`을 감싼 단독 실행 파일 (빌드 산출물) |
| `data.json` | 커리큘럼 원본 데이터 (트랙 → 유닛 → 레슨 → 문항). **문항 수정은 여기서.** |
| `build.mjs` | 검증 후 `data.json` → `app.html` 주입 + `index.html` 생성 |
| `check.mjs` | DESIGN.md 규칙의 기계 강제 버전. `build.mjs`도 이걸 불러 씁니다. |
| `dupcheck.mjs` | 같은 지식을 반복해 묻는 문항 찾기 |

```bash
node check.mjs      # 데이터 검증 (오류 있으면 종료 코드 1)
node dupcheck.mjs   # 중복 문항 점검
node build.mjs      # 주입 + index.html 생성
```

## 트랙 구조

`data.json`은 **트랙 배열**입니다. 엔진(문항 유형·간격 반복·스트릭·월반·동기화·내보내기·경로 UI)은
전부 공용이고, 트랙은 콘텐츠와 규칙 묶음(`kind`)만 갈아 끼웁니다.

```json
{ "schema": 3, "app": { "title": "임플란트 아카데미" }, "tracks": [
  { "id": "bridge",  "kind": "bridge",    "draft": true, "useLog": true, "bands": [...5단계...], "units": [...] },
  { "id": "implant", "kind": "knowledge", "speech": false, "bands": [...5단계...], "units": [...] },
  { "id": "english", "kind": "language",  "bands": [...A1.1~B1.1...], "units": [...] }
]}
```

- `tracks[0]`이 기본 트랙, 앱 이름은 `app.title`. live 트랙이 2개 이상이면 상단에 **트랙 전환 칩**이 켜집니다.
- `kind: "bridge"`는 용어 짝 → 개념 → 영어 문장 조립 → 설명해 보기 템플릿([DESIGN.md §9.5](DESIGN.md)),
  `kind: "knowledge"`는 용어 짝→4지선다·OX·빈칸→절차 배열, `kind: "language"`는 듣기→…→문장 조립과 문법 축을 씁니다.
- `draft: true`면 문항마다 "검수 전" 배지가 붙습니다(검수한 문항에 `verified: true`). `useLog: true`면 "업무에서 써먹었어요" 기록과 표현 노트가 켜집니다.
- 진도·복습 카드 ID는 이름 기반(`implant:basics/a`)이라 유닛을 재배치해도 기록이 어긋나지 않습니다.

## 커리큘럼 (임플란트 × 영어 — 기본 트랙)

**5단계 · 6유닛 · 24레슨 · 144문항** — 임플란트 지식을 배우는 레슨 안에서 그 내용을 바로 영어로 조립하고 설명합니다. 영상 제작 업무(해외용 영상·스크립트·해외 법인 소통)를 기준으로 짰고, 제조 공정·소재는 의도적으로 뺐습니다.

| 단계 | 유닛 | 레슨 |
|---|---|---|
| **1** 기본 개념 | 임플란트의 뼈대 | 임플란트란 · 세 부품 · 골유착 · 초기/2차 고정 |
| **2** 제품 구조 | 픽스처 들여다보기 | 몸통 모양 · 나사산 · 지름과 길이 · 연결 방식 |
| | 어버트먼트와 보철 | 어버트먼트 종류 · 나사/시멘트 고정 · 힐링·플랫폼 스위칭 · 보철 종류 |
| **3** 시술 흐름 | 수술에서 보철까지 | 진단과 계획 · 수술 · 뼈가 부족할 때 · 하중과 보철 완성 |
| **4** 품질·규제 | 규제와 라벨, 그리고 말조심 | ISO 표준 · FDA/CE/식약처 · 라벨과 IFU · 광고 표현의 선 |
| **5** 영상 업무 영어 | 영상 제작 현장 영어 | 스크립트·내레이션 · 피드백 · 세미나 촬영 · 런칭 영상 납품 |

> ⚠️ 일반론으로 쓴 **초안**입니다. 앱에서 "이 문항 이상해요"로 신고하면 내보내기 파일에 담기고, 검수 결과에 따라 수정합니다.

## 커리큘럼 (임플란트 임상)

**5단계 · 5유닛 · 20레슨 · 120문항** — 기초 → 진단 → 수술 → 보철 → 유지·상담. 진료실 현장 쪽 지식입니다.
레슨마다 용어 짝 → 4지선다·OX·빈칸 → 절차 배열 순서로 진행합니다 ([DESIGN.md §9](DESIGN.md)).

## 커리큘럼 (생활 영어)

**7개 레벨 밴드 · 22개 유닛 · 88개 레슨 · 528문항** (A1.1 → B1.1)

밴드마다 담당 문법이 있고, 각 밴드는 *문법 유닛 → 그 문법을 쓰는 상황 유닛* 순서입니다.
아직 배우지 않은 문법이 문항에 등장하면 `check.mjs`가 오류로 막습니다 — 이것이 커리큘럼이
체계를 유지하는 장치입니다 ([DESIGN.md §3.5](DESIGN.md)).

| 밴드 | 담당 문법 | 유닛 |
|---|---|---|
| **A1.1** 영어의 뼈대 | be동사·인칭대명사·관사·복수형 | 나와 너 · 이것과 저것 · 첫 인사와 소개 |
| **A1.2** 매일의 동작 | 일반동사 현재·3인칭 -s·do/does | 매일 하는 일 · 묻고 답하기 · 하루 일과 |
| **A1.3** 지금, 여기 | 현재진행형·전치사 | 지금 하는 중 · 카페와 식당 · 길 위에서 · 쇼핑 |
| **A2.1** 지난 일 말하기 | 과거시제(be·규칙·불규칙)·did | 어제는 어땠어요 · 지난 일 말하기 · 날씨와 스몰토크 |
| **A2.2** 앞일과 의무 | will·be going to·should·have to·must | 앞으로의 일 · 해야 하는 일 · 일과 약속 · 공항과 비행기 |
| **A2.3** 견주어 말하기 | 비교급·최상급·수량 표현 | 견주어 말하기 · 호텔에서 |
| **B1.1** 문장을 잇다 | 현재완료·관계대명사 | 해 본 적 있어요 · 설명을 덧붙이기 · 감정과 의견 |

## 문항 유형

레슨은 6문항 고정입니다. 영어 트랙은 **듣기 → 인식 → 조립 → 말하기**, 임상 트랙은 **용어 짝 → 개념·판단 → 절차**, 임플란트 × 영어 트랙은 **용어 짝 → 개념 → 영어 조립 → 설명** 순서를 따릅니다 — 자세한 규칙은 [DESIGN.md](DESIGN.md).

| 유형 | 하는 일 | 필수 필드 |
|---|---|---|
| `listen` | TTS로 문장을 들려주고 보기에서 고르기 (천천히 듣기 지원) | `audio`, `options`(4), `answerIndex` |
| `speak` | 문장을 따라 말하면 음성 인식으로 단어별 채점 — **선택 유형** (신규 유닛은 저작하지 않음) | `text`, `meaning` |
| `wordbank` | 단어 타일을 눌러 영어 문장 조립 | `prompt`, `answer`, `extra`(오답 타일), `accept`(대체 정답, 선택) |
| `choice` | 4지선다 | `prompt`, `options`(4), `answerIndex` |
| `blank` | 빈칸 채우기 (`___` 자리에 타일) | `prompt`, `hint`, `options`(4), `answerIndex` |
| `ox` | O/X 판단 | `prompt`, `answerBool` |
| `match` | 영어↔뜻 짝 맞추기 | `pairs`(4쌍) |
| `order` | 대화 순서 배열 (유닛 마지막 레슨의 캡스톤) | `sequence`(3~5) |
| `explain` | 설명해 보기 — 떠올리거나 적은 뒤 모범답안의 포인트로 자기채점 (60% 이상 통과) | `prompt`, `points`(2~4), `model` |

모든 문항에 `explanation`이 필요합니다. 저작 규약: 정답은 `answerIndex: 0`에 두면
화면 순서는 엔진이 렌더마다 섞습니다. 규칙의 정확한 정의는 `check.mjs`에 있습니다.

### 음성 기능이 없는 브라우저에서는

- **TTS 미지원**: `listen` 문항이 세션에서 제외됩니다 (답을 글로 보여 주는 것보다 정직합니다).
- **음성 인식 미지원 / 마이크 끔**: `speak` 문항이 세션에서 제외됩니다. 레슨이 막히지 않습니다.
- 말하기 문항의 "지금은 말하기 어려워요"는 그 문항을 채점에서 제외합니다 — 정답 처리가 아닙니다.
- 마이크와 자동 듣기는 프로필에서 각각 끌 수 있습니다.

### 발음 채점 방식

목표 문장을 정규화(소문자화·문장부호 제거·축약형 전개)한 뒤, 인식 결과에 몇 개 단어가 들어 있는지 봅니다. **70% 이상이면 통과**, 놓친 단어는 피드백에 물결 밑줄로 표시됩니다. 순서는 보지 않습니다 — 인식기가 어순을 자주 흔들기 때문입니다.

## 학습 장치

- **오늘의 복습(간격 반복)** — 푼 문항은 모두 복습 카드가 됩니다. 첫 시도에 맞히면 1→3→7→14→30일 간격으로 미뤄지고, 틀리면 내일 다시 나옵니다. 홈 첫 줄이 오늘의 복습(최대 8장, 여러 레슨을 섞어서)입니다
- **기억 지표** — XP 대신 **장기 기억**(7일 간격 복습을 통과한 카드)·익히는 중·오늘 복습 수를 보여 주고, 프로필에 **7일 뒤 기억률**을 표시합니다
- **하트 없음** — 틀려도 벌점이 없습니다. 오답은 레슨 끝에 재출제되고 복습 상자 1로 돌아갑니다 (월반 시험만 하트 3개)
- **설명해 보기** — 레슨 끝의 서술 문항. 적은 답은 내보내기 파일에 담겨 AI가 재평가할 수 있습니다
- **표현 노트 · 써먹은 기록** — 배운 영어 문장 모음. 업무에서 실제로 쓴 날 "써먹었어요"를 누릅니다
- **이 문항 이상해요** — 모든 피드백에서 신고할 수 있고, 이유와 함께 기록됩니다
- **학습 기록 내보내기** — 프로필 → 파일로 저장/클립보드 복사. 시도 로그·복습 카드·서술 답안·써먹은 기록·신고와 해당 문항 내용을 JSON 하나로 담습니다. Claude나 Codex CLI에 넘겨 효과 분석을 받으세요
- **월반 시험** — 잠긴 단계의 "여기부터 시작". 10문항·하트 3개 시험을 통과하면 앞 레슨을 건너뜁니다
- **클라우드 동기화(선택)** — 서버 주소·코드를 넣으면 기록이 자동 저장되고 기기 간 이어집니다 ([DEPLOY.md](DEPLOY.md) 참고)
- 레슨 시작 시 **'오늘의 표현'** 카드 — 조립·말하기할 문장을 먼저 보여 주고 들려줍니다
- 별점(첫 시도 정답률 기준 1~3개), 연속 학습일(스트릭), 정답 문장 다시 듣기, 효과음, 다크 모드
- 예전 오답 노트 기록은 첫 실행 때 오늘의 복습 카드로 옮겨집니다
