# 임플란트 아카데미 🦷

듀오링고 스타일의 단계별 임플란트 학습 웹앱. 모바일 우선 디자인, 설치·서버 없이 HTML 파일 하나로 동작합니다.

**바로 학습하기 → https://yurang2.github.io/implant-academy/**

## 사용 방법

- 위 주소를 열면 바로 시작됩니다. 내려받은 경우 `index.html`을 브라우저로 열어도 동일하게 동작합니다.
- 처음 접속 시 **성명(한글 2~4글자)** 을 입력하면 프로필이 만들어지고, 같은 기기에서 같은 이름을 입력하면 학습 기록이 다시 로드됩니다.
- 학습 데이터는 브라우저 `localStorage`에 저장됩니다(기기별 저장 — 서버 없음).

## 구성

| 파일 | 역할 |
|---|---|
| `app.html` | 앱 본체 (스타일 + 마크업 + 로직 + 커리큘럼 데이터). 수정은 이 파일에서. |
| `index.html` | `app.html`을 감싼 단독 실행 파일 (빌드 산출물) |
| `build.mjs` | `app.html` → `index.html` 빌드 + `data.json` 커리큘럼 주입/검증 |
| `data.json` | 커리큘럼 원본 데이터 (유닛 → 레슨 → 문항) |

빌드: `node build.mjs` (data.json이 있으면 검증 후 주입)

## 커리큘럼

5개 유닛 × 4개 레슨 × 6문항 = 총 120문항

1. **임플란트 기초** — 정의·3요소·골유착·기초 해부
2. **진단과 치료계획** — 영상검사·골질/골량·전신질환·치료계획
3. **수술 과정** — 식립·뼈이식(GBR)·상악동 거상술·수술 후 관리
4. **보철 과정** — 2차 수술·인상채득·보철물 종류·장착과 교합
5. **유지관리와 상담** — 주위염·홈케어·문제 대처·환자 상담

## 문항 유형

- `choice` 4지선다 · `ox` O/X 판단 · `blank` 빈칸 채우기 · `match` 짝 맞추기 · `order` 순서 배열

## 게임 요소

- 레슨당 하트 5개 (오답 시 차감, 소진 시 재도전)
- 오답 문항은 레슨 끝에 재출제 (맞힐 때까지)
- XP: 첫 시도 정답 +10 / 재시도 정답 +5 / 퍼펙트 보너스 +20
- 별점(정답률 기준 1~3개), 연속 학습일(스트릭)
- 효과음(프로필에서 끄기 가능), 다크 모드 자동 지원
